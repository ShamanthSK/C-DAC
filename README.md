## Assignment Workflow Rules

1. **One Assignment = One Folder**: All questions for a single assignment belong to the same assignment directory (`Assignment-XX`).
2. **Questions PDF**: Combined questions PDF (`Assignment-XX-Questions.pdf`).
3. **Individual Source Code**: Each question has its own clean, runnable source code file named sequentially (`Q01.java`, `Q02.java`, etc.).
4. **Single Combined Answers PDF**: `Assignment-XX-Answers.pdf` containing the Assignment Title, Question, Logic/Explanation, Source Code, and Expected Output for every question in that assignment.
